1. 功能概览

PolyAnalyzer 提供五个标签页：

标签页用途输入格式
GPC凝胶渗透色谱汇总与叠加图.rst / .xls / .xlsx
Mw分子量分布与区间统计.rst / .xls / .xlsx
DSC差示扫描量热分段与循环分析.txt
IR红外 DPT 单谱与叠加谱.dpt
其他清理已知输出目录目录

顶部语言选择器可切换中文和英文。已访问的标签页会保留目录、文件选择、参数、进度和输出状态。

2. 通用操作

  1. 在目标分析标签页选择或输入数据目录。
  2. 等待文件列表加载完成。切换目录时旧文件选择会立即清空。
  3. 选择文件并调整参数。
  4. 点击"运行"。分析期间目录和文件控件不可修改。
  5. 观察进度。成功、超时和分析异常都会保留在当前标签页。
  6. 完成后点击"打开目标文件夹"查看结果。
引擎预热：应用打开后，分析引擎（Python sidecar）会在后台自动预热约数秒到十几秒。预热期间窗口顶部会显示"引擎预热中，首次分析可能稍慢"的横幅，横幅消失即表示预热完成。在此期间发起分析不会出错，只是首次分析需要多等一会儿。

文件列表加载失败时，列表下方会显示错误。请检查目录是否存在、格式是否正确，以及 sidecar 是否可启动。

3. GPC

操作

  1. 选择包含 .rst 或 GPC 仪器 Excel 导出文件（.xls/.xlsx）的数据目录。
  2. 输入输出文件名，默认值为当天日期 YYYYMMDD。
  3. 如只处理部分文件，启用"选择部分文件"后在列表中选择。
  4. 选择是否保存样品信息（CSV）、图片（PNG）和绘图数据（XLSX）。
  5. 已有同名输出时，确认后启用"确认覆盖"。
  6. 点击"运行"。

输出

结果写入数据目录同级的 GPC_output/：

  • {输出名}.png：叠加色谱图（logMW–dw/dlogM 曲线，图例为样品名）
  • {输出名}.csv：分子量汇总（Mp、Mn、Mw、Mz、Mz+1、Mv、PD）
  • {输出名}.xlsx：绘图数据（启用时），每样品一个 sheet

4. Mw

操作

  1. 选择包含 .rst 或 GPC 仪器 Excel 导出文件的数据目录和待分析文件。
  2. 在"区域设置"中选择或新增分子量分割位置。
  3. 在"画图设置"中调整柱状图、Mw 曲线、表格、颜色、线宽和字号。
  4. 点击"运行"。

默认分割位置：

0, 5000, 10000, 50000, 100000, 500000,
1000000, 5000000, 10000000, 50000000

输出

结果写入数据目录同级的 Mw_output/：每个 .rst 文件一张图（以文件名命名）；Excel 导出文件中的每个样品一张图（以样品名命名），x 轴为分子量（对数刻度），包含区间分布表与 Mn/Mw/PDI 统计表。

5. DSC

操作

  1. 选择包含 .txt 文件的数据目录和待分析文件。
  2. 选择是否保存分段数据、绘制分段曲线和循环对比图。
  3. 只有启用"保存分段数据"和"绘制循环对比图"时，保存循环对比图才会生效。
  4. 调整峰方向、居中、左右边界和绘图样式。
  5. 点击"运行"。

桌面前端不会要求 Python 打开交互式图片窗口，DSC 的 display_pic 固定为 false。界面中被禁用的依赖选项也会以 false 提交。

输出

  • DSC_Cycle/：分段数据和循环对比结果
  • DSC_Pic/：分段曲线图片

两个目录位于所选数据目录的同级位置。

6. IR

操作

  1. 选择包含 .dpt 文件的数据目录。
  2. 选择一个或多个 DPT 文件。
  3. 单谱曲线默认使用红色，可继续调整颜色、透明背景、线宽、坐标轴和字号。
  4. 按需启用"绘制多样品叠加图"。启用后可以选择是否按峰归一化。
  5. 启用归一化后输入参考峰位，默认 1450 cm⁻¹。程序会在该峰位前后 80 cm⁻¹ 内寻找最大吸光度，并将各样品参考峰统一到吸光度 0.6。
  6. 点击"运行"。

输出

IR 输出位于应用可写数据根目录的 IR_output/：

IR_output/
├── individual/          单个样品谱图
├── dpt_overlay.png      叠加谱图（启用叠加时生成）
└── manifest.json        输入和输出清单

7. 设置预设

Mw、DSC 和 IR 分别保存自己的绘图预设，互不覆盖。每个模块可：

  • 从设置列表切换预设
  • 输入名称保存当前设置
  • 删除非默认预设

GPC 不显示预设管理面板。

8. 清理输出

"其他"标签页调用 system.clean_output。操作步骤：

  1. 选择一个现有数据目录。
  2. 启用"清理文件夹"。
  3. 点击"执行清理"，并在弹出的确认框中再次确认。

后端只会检查并重建已知输出目录。以下目录位于所选数据目录同级位置：

  • Mw_output/
  • GPC_output/
  • DSC_Cycle/
  • DSC_Pic/

IR 的 IR_output/ 位于应用可写数据根目录。符号链接和其他目录不会被当作输出目录清理。

9. 输入格式

GPC / Mw：.rst

仪器（Cirrus/Waters 类）导出的文本格式，包含分子量平均值（MW_Averages）和切片表（Slice_Table）数据段。

GPC / Mw：Excel 导出（.xls / .xlsx）

GPC 仪器软件的 Excel 导出格式，程序自动识别，无需固定列数：

  • 数据表：表头含 LogM 列，与以样品名命名的 MMD（dw/dlogM 分布）和 Cumulative（累积重量分数）列成对出现，如 26-2613 (GPP-262-1#) MMD。任意样品数、任意列数均可识别；缺失 MMD 或 Cumulative 列时会自动从另一列补算。
  • Results 汇总表（可选）：含 Mw (g/mol)、Mn (g/mol)、Mz (g/mol)、Mz1 (g/mol)、Mv (g/mol)、Mp (g/mol)、Mw / Mn 列，样品名在第一列，千分位逗号自动去除。缺失时不影响画图。

GPC 叠加图与 Mw 分布图的单位与 .rst 版本完全一致（logMW–dw/dlogM；Mw 图 x 轴为线性分子量的对数刻度）。

DSC：.txt

文件应包含时间、温度、热流和方法信息，以便识别并分割循环。

IR：.dpt

文件必须包含至少两行有限数值数据，每行由波数和吸光度组成。无效、NaN 或无限值数据会被拒绝或跳过。

10. 常见问题

文件列表为空

  • 确认目录存在。
  • 确认扩展名分别为 .rst、.xls、.xlsx、.txt 或 .dpt。
  • 等待加载结束并查看列表下方错误。

首次分析较慢 / "引擎预热中"横幅

引擎在应用打开后自动预热（加载绘图组件、构建字体缓存）。横幅消失后首次分析即可快速完成；同一次应用会话内后续分析不受影响。

分析超时

目录和系统请求约 30 秒超时，分析请求约 5 分钟超时。超时后应用会终止并重置 sidecar，下一次请求会启动新进程。

输出已存在

GPC 需要启用"确认覆盖"。其他模块按自身输出规则生成或替换目标目录。

打不开输出目录

确认目标目录已经生成且当前用户有访问权限；错误会显示在应用中。

11. 命令行

PolyAnalyzer 同时提供批量分析命令行 poly：

poly --help
poly gpc --datadir ./datapath --output-name batch-001
poly mw  --datadir ./datapath --ranges 0-50000,50000-100000
poly dsc --datadir ./datapath
poly clean --datadir ./datapath --yes

完整说明见安装目录下的 CLI_USAGE.md 与 CLI_USAGE_EN.md。

1. Overview

PolyAnalyzer provides five tabs:

TabPurposeInput formats
GPCGPC summary and overlaid chromatograms.rst / .xls / .xlsx
MwMolecular-weight distribution and segment statistics.rst / .xls / .xlsx
DSCDSC segment and cycle analysis.txt
IRIR DPT single and overlay spectra.dpt
OtherClean known output directoriesdirectory

The language selector in the header switches between Chinese and English. Visited tabs keep their directory, file selection, parameters, progress and output state.

2. Common workflow

  1. Select or enter a data directory in the target analysis tab.
  2. Wait for the file list to load. Previous selections are cleared when the directory changes.
  3. Select files and adjust parameters.
  4. Click "Run". Directory and file controls are locked during analysis.
  5. Watch the progress. Success, timeout and errors are kept in the current tab.
  6. Click "Open Output Folder" when finished.
Engine warmup: after the app opens, the analysis engine (Python sidecar) warms up in the background for a few seconds. A banner "Engine warming up — the first analysis may take a moment…" appears at the top and disappears when the engine is ready. Starting an analysis during warmup is safe; the first run just takes a little longer.

If the file list fails to load, an error appears below the list. Check that the directory exists, the formats are correct, and the sidecar can start.

3. GPC

Workflow

  1. Select a directory containing .rst files or GPC instrument Excel exports (.xls/.xlsx).
  2. Enter an output name; it defaults to today's date YYYYMMDD.
  3. To process only some files, enable "Select partial files" and pick them in the list.
  4. Choose whether to save sample info (CSV), image (PNG) and plot data (XLSX).
  5. If outputs with the same name exist, enable "Confirm overwrite".
  6. Click "Run".

Outputs

Results are written to GPC_output/ next to the data directory:

  • {output-name}.png — overlaid chromatograms (logMW–dw/dlogM curves, legend = sample names)
  • {output-name}.csv — molecular-weight summary (Mp, Mn, Mw, Mz, Mz+1, Mv, PD)
  • {output-name}.xlsx — plot data (when enabled), one sheet per sample

4. Mw

Workflow

  1. Select a directory containing .rst or GPC Excel export files, then the files to analyze.
  2. Choose or add molecular-weight segment positions in "Region settings".
  3. Adjust bars, Mw curve, tables, colors, line widths and font sizes in "Plot settings".
  4. Click "Run".

Default segment positions:

0, 5000, 10000, 50000, 100000, 500000,
1000000, 5000000, 10000000, 50000000

Outputs

Results are written to Mw_output/ next to the data directory: one figure per .rst file (named after the file), and one figure per sample for Excel exports (named after the sample). The x-axis is molecular weight on a log scale; the figure includes the segment table and the Mn/Mw/PDI stats table.

5. DSC

Workflow

  1. Select a directory containing .txt files and the files to analyze.
  2. Choose whether to save segment data, plot segment curves and plot cycle comparisons.
  3. Cycle comparison saving only takes effect when both "Save segment data" and "Plot cycle comparison" are enabled.
  4. Adjust peak orientation, centering, left/right boundaries and plot styles.
  5. Click "Run".

The desktop frontend never asks Python to open interactive image windows; DSC's display_pic is always false. Disabled dependent options are also submitted as false.

Outputs

  • DSC_Cycle/ — segment data and cycle comparison results
  • DSC_Pic/ — segment curve images

Both directories sit next to the selected data directory.

6. IR

Workflow

  1. Select a directory containing .dpt files.
  2. Select one or more DPT files.
  3. Single-spectrum curves are red by default; colors, transparent background, line width, axes and font sizes can be adjusted.
  4. Enable "Draw multi-sample overlay" if needed; optionally normalize by peak.
  5. When normalization is enabled, enter a reference peak position (default 1450 cm⁻¹). The program finds the maximum absorbance within ±80 cm⁻¹ of that position and scales every sample's reference peak to absorbance 0.6.
  6. Click "Run".

Outputs

IR outputs are written to IR_output/ under the app's writable data root:

IR_output/
├── individual/          per-sample spectra
├── dpt_overlay.png      overlay plot (when enabled)
└── manifest.json        input/output manifest

7. Settings profiles

Mw, DSC and IR keep separate plot presets that never overwrite each other. Each module can:

  • switch presets from the settings list
  • save the current settings under a name
  • delete non-default presets

GPC has no preset panel.

8. Clean outputs

The "Other" tab calls system.clean_output. Steps:

  1. Select an existing data directory.
  2. Enable "Clean folders".
  3. Click "Run clean" and confirm in the popup.

The backend only recreates known output directories, located next to the selected data directory:

  • Mw_output/
  • GPC_output/
  • DSC_Cycle/
  • DSC_Pic/

IR's IR_output/ lives under the app's writable data root. Symlinks and other directories are never treated as output directories.

9. Input formats

GPC / Mw: .rst

Text exports from Cirrus/Waters-style instruments, containing the molecular-weight averages (MW_Averages) and the slice table (Slice_Table) sections.

GPC / Mw: Excel exports (.xls / .xlsx)

Excel exports from GPC instrument software are auto-detected — any number of columns is supported:

  • Data sheet: a header row containing LogM columns paired with sample-named MMD (dw/dlogM distribution) and Cumulative (cumulative weight fraction) value columns, e.g. 26-2613 (GPP-262-1#) MMD. Missing MMD or Cumulative columns are derived from the other series automatically.
  • Results sheet (optional): columns Mw (g/mol), Mn (g/mol), Mz (g/mol), Mz1 (g/mol), Mv (g/mol), Mp (g/mol), Mw / Mn with sample names in the first column; thousands separators are stripped automatically. Plotting still works without it.

GPC overlay and Mw figures use exactly the same units as the .rst version (logMW–dw/dlogM; the Mw x-axis is linear molecular weight on a log scale).

DSC: .txt

Files must contain time, temperature, heat-flow and method information so cycles can be identified and split.

IR: .dpt

Files must contain at least two rows of finite numeric data, each row being wavenumber and absorbance. Invalid, NaN or infinite values are rejected or skipped.

10. Troubleshooting

Empty file list

  • Check that the directory exists.
  • Check that extensions are .rst, .xls, .xlsx, .txt or .dpt.
  • Wait for loading to finish and read the error below the list.

First analysis is slow / "Engine warming up" banner

The engine warms up automatically after the app opens (loading plotting components and building the font cache). Once the banner disappears, the first analysis runs quickly; later analyses in the same session are unaffected.

Analysis timeout

Directory and system requests time out after ~30 seconds, analysis requests after ~5 minutes. After a timeout the app kills and resets the sidecar; the next request starts a new process.

Outputs already exist

GPC requires "Confirm overwrite". Other modules generate or replace their target directories according to their own output rules.

Cannot open the output folder

Make sure the output directory was generated and the current user has access; errors are shown in the app.
